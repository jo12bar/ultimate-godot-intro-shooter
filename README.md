# Ultimate Godot Intro - 2D Shooter

My implementation of Clear Code's 2D Shooter game from the
[_Ultimate Introduction to Godot 4_][clearcode-vid] video. It's mostly the same
as the original, with some level layout changes and other stuff. The code is
actually quite different in some places from me messing around with it. See
also [Clear Code's GitHub repository][clearcode-repo].

[clearcode-vid]: https://www.youtube.com/watch?v=nAh_Kx5Zh5Q
[clearcode-repo]: https://github.com/clear-code-projects/UltimateGodotIntro2D
